# AI Acknowledgment

## Vector Dynamics — Senior Design Project

This project used OpenAI's ChatGPT as an AI-assisted development tool during portions of software development, documentation, debugging, and testing.

### Scope of AI Assistance

AI assistance included:

- Generating and refining Python and C++ code for vehicle detection, tracking, prototype sensor fusion, and communication protocols.
- Supporting YOLO-based detection and Kalman-filter implementation and testing.
- Creating synthetic radar and rear-vehicle detection scenarios.
- Assisting with debugging, software integration, automated tests, and documentation.

### Human Oversight and Verification

The Vector Dynamics team is responsible for engineering decisions, system requirements, review and verification of code, testing, and final deliverables. AI-assisted outputs require human review and should not be assumed correct or validated solely because they pass software tests.

### Safety and Validation Limitations

Some current software uses synthetic sensor inputs and experimental algorithms. Software simulation does not establish physical-system safety, accuracy, regulatory compliance, or readiness for use on public roads. Hardware integration, calibration, and field validation remain necessary.

This disclosure describes AI assistance in the development process. It should be updated if the scope of AI use changes and checked against the course or institution's disclosure requirements.
